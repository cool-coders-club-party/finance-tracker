To set the token to a var for easier testing:
set TOKEN=<whateverTheTokenIs>

create a portfolio:
curl -i -X POST http://localhost:8083/api/portfolios -H "Authorization: Bearer %TOKEN%" -H "Content-Type: application/json" -d "{\"name\":\"My first portfolio\"}"

set portfolioId for easier use:
set pId=<theId>

List your portfolios:
curl -i http://localhost:8083/api/portfolios -H "Authorization: Bearer %TOKEN%"

buy:
curl -i -X POST http://localhost:8083/api/portfolios/%PID%/buy -H "Authorization: Bearer %TOKEN%" -H "Content-Type: application/json" -d "{\"ticker\":\"AAPL\",\"quantity\":10}"

sell:
curl -i -X POST http://localhost:8083/api/portfolios/%PID%/sell -H "Authorization: Bearer %TOKEN%" -H "Content-Type: application/json" -d "{\"ticker\":\"AAPL\",\"quantity\":5}"

holdings:
curl -i http://localhost:8083/api/portfolios/%PID%/holdings -H "Authorization: Bearer %TOKEN%"

trades history(oldest first):
curl -i http://localhost:8083/api/portfolios/%PID%/trades -H "Authorization: Bearer %TOKEN%"

Profit and Loss per holding:
curl -i http://localhost:8083/api/portfolios/%PID%/performance -H "Authorization: Bearer %TOKEN%"
